# PRISM — Investment Simulator

> 배우고(Academy) → 직접 투자하고(Trade) → 나의 투자 습관을 되돌아보는(Report) 교육용 투자 시뮬레이션 게임

배포 주소: https://prism72.streamlit.app

---

## 1. 프로젝트 소개

### 해결하려는 문제와 대상 사용자
- **대상 사용자:** 투자를 처음 접하는 고등학생·청소년
- **문제:** 투자를 배우려면 용어 암기나 실제 돈이 필요해서 어렵습니다. 그리고 많은 초보 투자자가 지식이 아니라 **불안·욕심 같은 마음 때문에** 실패합니다.

### 문제가 생기는 상황과 배경
뉴스에서 어떤 종목이 급등하면 '나만 뒤처질까' 불안해서 뒤늦게 사고, 급락하면 두려워서 팔았다가 반등을 놓칩니다. 이런 행동 편향은 책으로 읽을 때는 이해돼도 **직접 결정해 보기 전에는 내 습관이라고 느끼지 못합니다.**

### 기존 방식과의 차별점
| 기존 모의투자·교육 앱 | PRISM |
|---|---|
| 실제 종목과 시세를 쓰고 수익률만 보여 줌 | 가상 시나리오 3개를 쓰고 **왜 그렇게 결정했는지**를 분석 |
| 결과는 숫자(수익률) 위주 | 군중 심리·공포 매도·과잉 확신 등 **행동 편향을 찾아내 알려 줌** |
| 용어를 읽는 학습 | 학습 → 퀴즈 → 실전 → 리포트로 이어지는 **게임 흐름과 XP·배지** |

모든 기업·시장·뉴스는 교육용으로 만든 가상의 내용이며 실제 투자 권유가 아닙니다.

## 2. 사용법

1. **Home** — 서비스 소개를 읽고 `Academy에서 시작하기` 버튼을 누릅니다. 오른쪽 위 `monochrome` 스위치로 라이트/다크 화면을 바꿀 수 있습니다.
2. **Academy** — 투자 개념 카드 5장을 읽고 퀴즈 5문제 중 3문제 이상 맞히면 Trade가 열립니다. (바로 해 보고 싶으면 Trade의 `학습 건너뛰고 바로 시작`)
3. **Trade** — 시장(시나리오)을 하나 고릅니다. 매달 뉴스와 종목 가격을 보고, 돌발 상황이 뜨면 먼저 답합니다. 슬라이더로 자산별 비중(%)을 정한 뒤 `한 달 보내기`를 누릅니다. 12개월을 모두 보내면 게임이 끝납니다.
4. **Report** — 최종 자산과 시장 대비 성적, 나의 투자 캐릭터, 발견된 행동 편향과 개선 팁, 월별 타임라인, 획득한 배지를 확인합니다.
5. **Glossary** — 막히는 용어를 검색합니다.

> 주의: 브라우저를 새로고침하면 진행 상황(XP·배지·게임 기록)이 초기화됩니다. 발표·시연 중에는 새로고침하지 마세요.

## 3. 주요 기능

| 기능 | 설명 |
|---|---|
| 개념 학습 + 퀴즈 | 카드 5장과 5문제 퀴즈. 통과해야 실전 입장 (정답 위치는 섞여 있음) |
| 시나리오 선택 | 같은 기업을 두고 서로 다른 1년을 보여 주는 가상 시장 3개 |
| 월별 투자 시뮬레이션 | 7개 자산(주식 5, 채권, 금)과 현금에 비중을 정하면 거래 비용 0.2%, 현금 이자를 반영해 한 달이 흐름 |
| 돌발 이벤트 | 달마다 뜨는 선택지. 어떤 보기를 고르느냐에 따라 그 달의 비중 제한이 달라지고 판단 유형이 기록됨 |
| 행동 편향 분석 | 군중 심리, 공포 매도, 과잉 확신, 확증 편향, 과잉 매매, 지나친 위험 회피와 잘한 점(분산 투자, 공포 속의 인내) 탐지 |
| 투자자 등급·캐릭터 | 시장 대비 수익과 최대 낙폭(MDD)으로 S/A/B/C 등급, 투자 성향 캐릭터 카드 |
| XP·레벨·배지 | 결정, 좋은 판단, 완주로 경험치를 얻고 배지 수집 |
| 용어 사전 | 검색 가능한 투자 용어 풀이 |
| 라이트/다크 모드 | monochrome 스위치와 모드별 배경 영상 |

## 4. 폴더 구조

```
main.py                 앱 입구: 페이지 설정, 페이지 등록, 상단 메뉴
views/                  화면(페이지) 하나당 파일 하나
  home.py  academy.py  trade.py  report.py  glossary_page.py
core/                   기능 코드
  game.py               게임 엔진 (턴 진행, 계산, 편향 분석, 정산)
  progress.py           XP·레벨·배지
  character.py          투자자 캐릭터 결정
  charts.py             그래프(SVG) 만들기
  ui.py / theme.py      공통 화면 조각, 색상·CSS 적용
data/                   가상 시장·시나리오·이벤트·퀴즈·용어·배지 데이터
assets/                 style.css, 배경 영상
```

## 5. 실행 방법

```bash
pip install -r requirements.txt
streamlit run main.py
```
Python 3.12 이상, Streamlit 1.50.0 기준입니다.

## 6. 예외 상황 처리

| 상황 | 처리 |
|---|---|
| 비중 합계가 한도(100% − 이벤트 최소 현금)를 넘음 | 한 달 보내기 버튼 비활성화, 화면에 한도 초과 표시, 엔진에서도 거부(`advance` → False) |
| 돌발 이벤트에 답하지 않고 진행 | 버튼 비활성화 후 "먼저 돌발 상황에 답해 주세요" 안내 |
| 퀴즈 통과 전 Trade 접근 | 잠금 화면 표시 |
| 이미 끝난 게임에서 다시 진행 / 이벤트 중복 응답 | 무시 (XP 중복 지급 방지 키 사용) |
| 잘못된 시나리오 번호 등 망가진 게임 상태 | `get_game()`이 새 게임으로 복구 |
| 투자 기록이 없는 상태로 Report 접근 | "아직 투자 기록이 없어요" 안내 |
| 용어 검색 결과 없음 | 안내 문구 표시 |
| 배경 영상 파일이 없거나 읽기 실패 | 영상 없이 기본 배경으로 정상 동작 |
| 총자산 0 또는 빈 기록으로 최대 낙폭 계산 | 0으로 나누지 않고 0 처리 |
